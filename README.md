# README

This project is a lightweight MVP for an all-in-one marketplace platform that brings together:

- artisan and professional service categories
- product marketplace listings
- job opportunities
- login and admin dashboard
- local browser storage for demo data

## Included categories

The homepage now includes expanded categories based on the artisan and professional service list, including:

- Building & Construction Trades
- Electrical, Power & Cooling
- Automotive & Transport Repair
- Fashion, Garment & Leatherworks
- Home Maintenance & Events
- Professional Services

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local web server.

Example:

```bash
python -m http.server 8000
```

Then open:

http://localhost:8000
